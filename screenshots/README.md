# 网易云音乐工具箱 - 功能页面说明

## 项目概述

网易云音乐工具箱（Music Toolbox）是一个全功能的网易云音乐管理工具，提供音乐搜索、下载、歌单同步等多项功能。

**版本**: v2.0.0

---

## 功能页面清单

### 1. 🎵 音乐搜索 (`/`)
**文件名**: `01_音乐搜索.png`

**功能描述**:
- 搜索音乐功能，支持输入歌曲名或歌手名
- 支持多个音源选择：网易云、QQ音乐
- 可配置每页结果数量（默认30条）
- 包含以下子功能标签页：
  - **搜索音乐**: 实时搜索歌曲
  - **歌单解析**: 解析歌单链接
  - **专辑解析**: 解析专辑信息
  - **音乐下载**: 下载音乐文件

**功能特性**:
- 支持同时勾选多个音源，结果会标注来源
- 可同时下载多个音源的搜索结果
- 支持多种音质选择

---

### 2. 📝 歌词查询 (`/lyrics`)
**文件名**: `02_歌词查询.png`

**功能描述**:
- 按歌曲名称查询歌词
- 按歌曲ID查询歌词
- 可选输入歌手名提高查询准确度

**功能特性**:
- 支持中文歌曲名查询
- 支持歌曲ID精确查询
- 快速获取 LRC 格式歌词

---

### 3. 📁 文件管理 (`/files`)
**文件名**: `03_文件管理.png`

**功能描述**:
- 管理下载的音乐文件
- 显示下载目录（默认: `downloads/`）
- 查看文件详细信息

**功能特性**:
- 显示文件大小和修改时间
- 支持文件的播放、下载、删除操作
- 支持按名称排序
- 支持文件批量删除
- 显示文件总数统计

**快捷操作**:
- ⏮️ 播放文件
- ⬇️ 下载文件
- 🗑️ 删除文件
- 编辑文件信息

---

### 4. 🔄 歌单同步 (`/sync`)
**文件名**: `04_歌单同步.png`

**功能描述**:
- 自动同步网易云歌单
- 配置定时同步任务
- 管理同步歌单列表

**配置选项**:
- **启用定时同步**: 开启后按设定周期自动同步歌单
- **歌单管理**: 添加或移除要同步的歌单（支持ID或链接）
- **同步音质**: 选择同步时的音乐音质
  - 标准、极高、无损、Hi-Res、环绕声、高清环绕、母带
- **调度方式**: 
  - 固定间隔（1小时、2小时、6小时等）
  - Cron 表达式（自定义时间表）
- **完全同步模式**: 删除本地在远程歌单中不存在的文件（谨慎使用）
- **去除重复文件**: 同步完成后删除内容相同的重复文件

**状态指示**:
- ✅ 同步服务已配置

---

### 5. ⚙️ 配置 (`/config`)
**文件名**: `05_配置.png`

**功能描述**:
- 管理应用设置和偏好
- 下载配置管理
- Cookie 配置管理

**配置标签页**:

#### 下载配置
- **下载目录**: 设置音乐文件保存位置
- **默认音质**: 选择下载音乐时的默认音质
- **音质写入文件名**: 文件名中附带音质标识（如"歌名 [极高].mp3"）
- **同时下载歌词**: 自动保存歌词 .lrc 文件
- **保存到本地**: 音乐文件保存到服务器本地
- **浏览器同时下载**: 浏览器也会下载文件副本

#### Cookie 配置
- 管理网易云音乐 Cookie
- 配置用户认证信息

---

### 6. 🔔 消息推送 (`/magicpush`)
**文件名**: `06_消息推送.png`

**功能描述**:
- 配置推送规则
- 管理推送消息模板
- 应用事件触发推送

**配置项**:

#### 推送规则
- **下载完成提示**: 文件下载完成时推送通知
- **同步完成提示**: 歌单同步完成时推送通知
- 支持启用/停用各项推送规则
- 配置推送地址（支持多个）

#### 消息模板
- 自定义推送消息内容
- 支持变量替换

**推送特性**:
- 共有 2 条预配置的推送规则
- 支持新增、编辑、删除推送规则
- 保存配置后立即生效

---

### 7. 📊 任务管理 (`/tasks`)
**文件名**: `07_任务管理.png`

**功能描述**:
- 查看所有任务执行记录
- 任务状态监控
- 任务历史管理

**任务状态**:
- 📋 **全部**: 显示所有任务
- ⚙️ **执行中**: 正在进行的任务
- ✅ **已完成**: 已完成的任务
- ❌ **失败**: 失败的任务

**快捷操作**:
- **自动刷新 (3s)**: 每3秒自动更新任务列表
- **清理已完成**: 删除已完成的任务记录

**特性**:
- 显示任务详细信息
- 实时刷新任务状态
- 下载音乐后任务记录会显示在此

---

### 8. 📋 运行日志 (`/logs`)
**文件名**: `08_运行日志.png`

**功能描述**:
- 实时监控应用运行日志
- 查看系统和任务执行记录
- 日志文件管理

**功能特性**:
- **实时监控**: 每3秒更新日志（可暂停）
- **日志文件选择**: 支持查看多个日志文件
- **日志过滤**: 显示最近1000条日志
- **倒序排列**: 最新日志在前
- **日志搜索**: 支持日志内容搜索

**快捷操作**:
- **暂停**: 停止实时监控
- **刷新**: 手动刷新日志
- **清空日志**: 清除所有日志内容

**可用日志文件**:
- `playlist_sync.log`: 歌单同步日志
- `music_api.log`: 音乐API日志
- `download.log`: 下载任务日志

---

### 9. 📚 API 文档 (`/api-docs`)
**文件名**: `09_API文档.png`

**功能描述**:
- 完整的 API 接口文档
- 网易云音乐 API 服务说明
- 接口调用示例

**API 分类**:

#### 核心业务 (7 个接口)
- `GET, POST /song`: 获取歌曲信息
- `GET, POST /api/lyrics/query`: 查询歌词
- `GET /api/lyrics`: 获取歌词
- `GET, POST /search`: 搜索音乐
- `GET, POST /playlist`: 获取歌单详情
- `GET, POST /album`: 获取专辑详情
- `GET, POST /download`: 下载音乐

#### 系统管理 (4 个接口)
- `GET /health`: 健康检查
- `GET /api/info`: API信息
- `GET /api/api-docs`: API文档JSON
- `GET /api-docs`: API文档页面

#### 定时同步 (4 个接口)
- `GET /sync/config`: 获取同步配置
- `POST /sync/config`: 保存同步配置
- `GET /sync/status`: 获取同步状态
- `POST /sync/now`: 立即同步

**API 版本**: v2.0.0

## 快速开始

### 启动服务

2. **前端**: `npm run dev` (运行在 http://localhost:3000)

### 使用功能
1. 打开浏览器访问 http://localhost:3000/
2. 使用账户 `admin/admin123` 登录
3. 选择所需功能进行操作
