# 前端重构计划 — 从 Bootstrap/jQuery 迁移到 Vuetify 3

## 目标

使用 **Vue 3 + Vuetify 3** 重写全部前端页面，后端 Flask API 不变。保持现有功能完整，提升视觉质感和交互体验。

## 现有页面清单（7 页）

| 路由 | 页面 | 核心功能 |
|------|------|----------|
| `/` | 业务操作 | 4 Tab：搜索音乐、歌单解析、专辑解析、下载。搜索结果卡片网格、歌单/专辑头部+曲目列表（带批量下载复选框）、下载输入+音质选择、歌曲详情 Modal+APlayer 播放。localStorage 历史记录 |
| `/files` | 文件管理 | downloads 目录文件表格（复选框、名称、MB 大小、时间）。音频文件 ▶ 播放（顶部 HTML5 audio）、文本文件 ✏ 编辑（Modal textarea+保存）、⬇ 下载、🗑 删除/批量删除。过滤：仅音频 Toggle + 扩展名输入 + 忽略大小写 |
| `/config` | 配置 | 3 Tab：同步配置（歌单管理 Cron/间隔）、下载配置（目录+模式）、Cookie 配置（textarea 编辑+验证） |
| `/magicpush` | 消息推送 | 2 Tab：Magic Push（推送卡片：名称、事件选择下拉、模板选择下拉、固定内容、URL 管理、测试发送）+ 消息模板（CRUD 模板：标题/内容占位符） |
| `/tasks` | 任务监控 | 下载任务列表（状态筛选：全部/执行中/已完成/失败），进度条，实时 3s 刷新 |
| `/logs` | 运行日志 | 日志文件下拉切换，倒序显示最近 1000 行，3s 自动刷新，暂停/恢复，清空 |
| `/api-docs` | API 文档 | 从 `/api/api-docs` JSON 渲染，折叠式分类卡片 |

## 侧边栏菜单（统一）

```
🏠 业务操作 → 📁 文件管理 → ⚙️ 配置 → 📨 消息推送 → 📊 任务监控 → 📋 运行日志 → 📖 API 接口文档
```

## API 端点（保持不动，前端直接调用）

所有 API 返回 `{status, success, message, data}` 格式。

| 方法 | 路径 | 用途 |
|------|------|------|
| GET/POST | `/song` | 歌曲信息（url/name/lyric/json） |
| GET/POST | `/search` | 搜索（keyword, limit） |
| GET/POST | `/playlist` | 歌单详情 |
| GET/POST | `/album` | 专辑详情 |
| GET/POST | `/download` | 下载（id, quality），支持流式 |
| GET/POST | `/sync/config` | 同步配置 |
| GET | `/sync/status` | 同步状态 |
| POST | `/sync/now` | 立即同步 |
| GET/POST | `/api/cookie` | Cookie 读写 |
| GET/POST | `/api/settings` | 通用设置 |
| GET/POST | `/api/push/config` | 推送配置 |
| POST | `/api/push/send` | 测试推送 |
| GET | `/api/events/catalog` | 事件目录 |
| GET | `/api/events/history` | 事件历史 |
| GET | `/api/files/list` | 文件列表 |
| POST | `/api/files/delete` | 删除文件 |
| GET | `/api/files/stream/<name>` | 文件流（?download=1） |
| GET | `/api/files/read/<name>` | 读文本 |
| POST | `/api/files/save` | 保存文本 |
| GET | `/api/tasks` | 任务列表 |
| GET | `/api/logs` | 日志内容 |
| POST | `/api/logs/cleanup` | 清理日志 |
| GET | `/api/api-docs` | API 文档 JSON |
| GET | `/health` | 健康检查 |

## 设计要求

- 使用 Vuetify 3 组件：v-navigation-drawer、v-app-bar、v-card、v-table、v-dialog、v-tabs、v-text-field、v-btn、v-chip、v-progress-linear、v-switch、v-select、v-textarea、v-data-table 等
- 保持深色/浅色主题切换能力
- 侧边栏导航常驻，当前页高亮
- Toast 通知使用 v-snackbar
- 音频播放使用 HTML5 audio（APlayer 可选）
- 表格支持排序、搜索、分页
- 响应式布局，移动端友好

## 优先级

1. 业务操作（核心功能）
2. 文件管理
3. 配置
4. 消息推送
5. 任务监控 + 运行日志 + API 文档
